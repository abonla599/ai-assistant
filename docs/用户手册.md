# AI智能助手 - 用户手册（Windows桌面版）

## 📦 安装指南

### 系统要求
- **操作系统**: Windows 10/11 (64位)
- **内存**: 至少 4GB RAM
- **磁盘空间**: 至少 500MB 可用空间

### 安装步骤

1. **下载安装包**
   - 从发布页面下载 `AI智能助手_Setup.exe`

2. **运行安装程序**
   - 双击安装包
   - 按照向导提示选择安装位置（默认：`C:\Program Files\AI_Assistant`）
   - 点击"安装"按钮

3. **完成安装**
   - 安装完成后，桌面会出现"AI智能助手"快捷方式
   - 开始菜单中也会创建相应快捷方式

## 🚀 启动应用

### 方法一：桌面快捷方式（推荐）
双击桌面上的"AI智能助手"图标

### 方法二：开始菜单
1. 点击"开始"按钮
2. 找到"AI智能助手"文件夹
3. 点击"AI智能助手"

### 首次启动说明
- 首次启动时，后端服务需要初始化（约3-5秒）
- 请耐心等待应用窗口自动弹出
- 如果看到命令行窗口，请**不要关闭**它（这是后端服务）

## 🔧 配置API密钥

### 方法一：通过配置文件
1. 打开安装目录（默认：`C:\Program Files\AI_Assistant`）
2. 找到 `run_backend\.env` 文件
3. 用记事本打开，填入您的API密钥：
   ```
   DEEPSEEK_API_KEY=你的DeepSeek密钥
   OPENAI_API_KEY=你的OpenAI密钥（可选）
   ```
4. 保存文件并重启应用

### 方法二：获取API密钥
- **DeepSeek**: 访问 https://platform.deepseek.com
- **OpenAI**: 访问 https://platform.openai.com

## 🔑 注册与登录（多用户）

从这一版起，**每个人用自己的身份**访问同一个助手：会话、附件、长期记忆都挂在身份上，
别人看不到您的，您也看不到别人的。

### 1. 打开就能注册
第一次打开会直接弹出一层登录界面，切到**注册**那页，自己填两项：

- **用户名**：自己起，被占用会当场提示，换一个即可
- **密码**：至少 8 位，自己记好——服务端只存它的 bcrypt 摘要，没有人能替您找回

成功后服务端发回**一枚个人令牌**，它只在这一屏出现一次，之后只存在您这台设备的
浏览器里（localStorage），关掉页面也还在。**密码不会被拿去当请求凭据**：它只用来
换令牌，换完就从输入框里清掉。

### 2. 换手机 / 重装 / 多台设备一起用
现在**不需要找管理员**：在新设备上用同一个用户名 + 密码登录即可，它会再发一枚令牌，
而旧设备那枚**继续有效**（手机、桌面、浏览器各算一台，最多同时留 8 枚，超了丢最老的）。

只有这一种情况才需要管理员动手：

- **怀疑密码泄露**——让他执行轮换，它会一次作废您**全部**设备的令牌：
  `POST /v1/admin/users/<您的 user_id>/rotate-token`

**忘了密码**不用找任何人：注册时您填过一个找回问题和它的答案，登录页点「忘记密码」，
按用户名 → 答案 → 新密码三步走完即可。两点要知道：

- 答案与新密码是**一次提交**的（中途不会告诉您"答案对不对"），所以填错了要整段重来；
- 改密成功之后，您**所有设备上的登录都会掉线**，用新密码重新登录即可——这正是它的目的。

**答案也忘了**就真没有路了：系统里没有邮件或短信通道，也没有任何人能替您改密码
（管理员手里只有停用、轮换、删号三件事）。那个账号的历史会话与记忆不会跟到新账号，
所以找回问题请填一个您**多年后还记得**的答案。

### 3. 被停用了怎么办
管理员停用某个用户后，他的令牌**当场失效**，而且**停用的账号连密码正确也登不进去**。
这个操作是**可逆的**：

```
POST /v1/admin/users/<user_id>/disable   # 停用
POST /v1/admin/users/<user_id>/enable    # 恢复，令牌无需重新发放
```

所以被停用又恢复之后，您**原来那枚令牌继续能用**，不必重新注册。

### 4. 界面上那几句提示分别是什么意思
| 您看到的 | 实情 | 该怎么办 |
| --- | --- | --- |
| 「还没有登录：用用户名和密码登录，或注册一个」 | 这台设备还没存过令牌 | 注册或登录一次 |
| 「登录已失效：本机令牌已被服务端拒绝（管理员撤销或轮换过），重新登录即可」 | 令牌存过、但已作废 | 重新登录；**不是您输错了口令** |
| 「登录失败：用户名或密码不正确」 | 用户名不存在、密码错、或账号被停用——服务端**刻意不分**这三种 | 核对用户名与密码；确定没输错就找管理员 |
| 「注册失败：该用户名已被占用」 | 名字撞了 | 换个用户名再点一次 |
| 「注册失败：密码至少 8 位」 | 密码太短 | 加长一点 |
| 「尝试次数过多，请稍后再试」(429) | 同一个来源十分钟内错太多次，或今天注册太多 | 等 10 分钟；正常登录注册不会被挡，见部署指南里"真实访客 IP 限流"一条 |

## 💡 使用技巧

### 聊天功能
- 在输入框中输入问题，按回车或点击发送
- 支持多轮对话，上下文会自动保留
- 可以切换不同的AI模型

### 会话管理
- 左侧列表显示所有历史会话
- 点击会话可切换到该对话
- 可以删除不需要的会话

### 记忆功能
- AI会自动记住重要的信息
- 可以在设置中查看和管理记忆
- 支持手动添加和删除记忆

## ❓ 常见问题

### Q: 应用无法启动怎么办？
A: 
1. 检查任务管理器中是否有 `run_backend.exe` 进程
2. 如果没有，尝试重新运行桌面快捷方式
3. 检查防火墙是否阻止了应用

### Q: 聊天没有响应？
A:
1. 确认已正确配置API密钥
2. 检查网络连接是否正常
3. 查看后端日志（在 `run_backend` 目录下的命令行窗口）

### Q: 如何完全卸载？
A:
1. 使用控制面板的"程序和功能"卸载
2. 或删除安装目录及开始菜单快捷方式
3. 如需清除数据，删除 `chroma_db` 文件夹

### Q: 如何更新到新版本？
A:
1. 先卸载旧版本
2. 下载新版安装包
3. 重新安装即可（注意备份 `.env` 文件中的密钥）
