# AI智能助手 - 用户手册（Windows桌面版）

## 📦 安装指南

### 系统要求
- **操作系统**: Windows 10/11 (64位)
- **内存**: 至少 4GB RAM
- **磁盘空间**: 至少 500MB 可用空间

### 安装步骤

1. **下载安装包**
   - 从发布页面下载 `AI智能助手_Setup.exe`

2. **运行安装程序**
   - 双击安装包
   - 按照向导提示选择安装位置（默认：`C:\Program Files\AI_Assistant`）
   - 点击"安装"按钮

3. **完成安装**
   - 安装完成后，桌面会出现"AI智能助手"快捷方式
   - 开始菜单中也会创建相应快捷方式

## 🚀 启动应用

### 方法一：桌面快捷方式（推荐）
双击桌面上的"AI智能助手"图标

### 方法二：开始菜单
1. 点击"开始"按钮
2. 找到"AI智能助手"文件夹
3. 点击"AI智能助手"

### 首次启动说明
- 首次启动时，后端服务需要初始化（约3-5秒）
- 请耐心等待应用窗口自动弹出
- 如果看到命令行窗口，请**不要关闭**它（这是后端服务）

## 🔧 配置API密钥

### 方法一：通过配置文件
1. 打开安装目录（默认：`C:\Program Files\AI_Assistant`）
2. 找到 `run_backend\.env` 文件
3. 用记事本打开，填入您的API密钥：
   ```
   DEEPSEEK_API_KEY=你的DeepSeek密钥
   OPENAI_API_KEY=你的OpenAI密钥（可选）
   ```
4. 保存文件并重启应用

### 方法二：获取API密钥
- **DeepSeek**: 访问 https://platform.deepseek.com
- **OpenAI**: 访问 https://platform.openai.com

## 🔑 注册与登录（多用户）

从这一版起，**每个人用自己的身份**访问同一个助手：会话、附件、长期记忆都挂在身份上，
别人看不到您的，您也看不到别人的。

### 1. 先要一枚邀请码
安装好的助手**不再有一把大家共用的访问口令**。第一次打开时，请在
**「设置 → 连接」**里填：

- **邀请码**：向管理员索取（管理员在服务器上执行 `tools\make-invite.bat`，
  一次一枚，用过即废）
- **用户名**：自己起，被占用会当场提示，换一个即可

注册成功后服务端会发回**一枚个人令牌**。它**只在这一屏出现一次**，之后只存在您这台
设备的浏览器里（localStorage），关掉页面也还在。

### 2. 令牌丢了 / 换设备 / 怀疑被别人拿到
令牌**没有"忘记密码"这条路**，找回来的动作叫**轮换**，只有管理员能做：

```
POST /v1/admin/users/<您的 user_id>/rotate-token
```

轮换后**旧令牌立刻作废**（不是"还能用一段时间"）。把管理员给您的新令牌填进
**「设置 → 连接」**即可；如果您已经注册过、又不想等管理员，也可以拿一枚新邀请码
重新注册一个身份——但那是**另一个人的账号**，历史会话不会跟过去。

### 3. 被停用了怎么办
管理员停用某个用户后，他的令牌**当场失效**。这个操作是**可逆的**：

```
POST /v1/admin/users/<user_id>/disable   # 停用
POST /v1/admin/users/<user_id>/enable    # 恢复，令牌无需重新发放
```

所以被停用又恢复之后，您**原来那枚令牌继续能用**，不必重新注册。

### 4. 界面上那几句提示分别是什么意思
| 您看到的 | 实情 | 该怎么办 |
| --- | --- | --- |
| 「还没有登录：请在「设置 → 连接」用邀请码注册」 | 这台设备还没存过令牌 | 注册一次 |
| 「登录已失效：本机令牌已被服务端拒绝（管理员撤销或轮换过）」 | 令牌存过、但已作废 | 找管理员轮换，或重新注册；**不是您输错了口令** |
| 「注册失败：邀请码无效」 | 码不存在 / 已用掉 / 已过期 / 被撤销，服务端刻意不分这几种 | 向管理员再要一枚 |
| 「注册失败：用户名已被占用」 | 码是好的，只有名字撞了 | 换个用户名再点一次 |
| 「尝试次数过多，请稍后再试」(429) | 同一个来源十分钟内猜错太多次 | 等 10 分钟；正常注册不会被挡，见部署指南里"共享限流桶"一条 |

## 💡 使用技巧

### 聊天功能
- 在输入框中输入问题，按回车或点击发送
- 支持多轮对话，上下文会自动保留
- 可以切换不同的AI模型

### 会话管理
- 左侧列表显示所有历史会话
- 点击会话可切换到该对话
- 可以删除不需要的会话

### 记忆功能
- AI会自动记住重要的信息
- 可以在设置中查看和管理记忆
- 支持手动添加和删除记忆

## ❓ 常见问题

### Q: 应用无法启动怎么办？
A: 
1. 检查任务管理器中是否有 `run_backend.exe` 进程
2. 如果没有，尝试重新运行桌面快捷方式
3. 检查防火墙是否阻止了应用

### Q: 聊天没有响应？
A:
1. 确认已正确配置API密钥
2. 检查网络连接是否正常
3. 查看后端日志（在 `run_backend` 目录下的命令行窗口）

### Q: 如何完全卸载？
A:
1. 使用控制面板的"程序和功能"卸载
2. 或删除安装目录及开始菜单快捷方式
3. 如需清除数据，删除 `chroma_db` 文件夹

### Q: 如何更新到新版本？
A:
1. 先卸载旧版本
2. 下载新版安装包
3. 重新安装即可（注意备份 `.env` 文件中的密钥）
