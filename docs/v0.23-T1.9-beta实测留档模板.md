- 篡改拒装（字节层）：`android/app/src/test/.../ApkDownloaderTest.java`
  · `oneFlippedBitInAnOtherwisePerfectPackageIsRefused`——整包仅翻最后 1 bit，
  判「校验值不一致，这个包不是发布的那一份」，`.part` 就地焚掉、正式名不落盘；
  · `aSwappedPackageFailsDigestAndLeavesNothing`（整包替换）、`anEmptyBodyIsRefused...`（空包）同族。
- 无校验值不下第一字节：`noDigestNoNetwork`（同文件）+ 原生 `Updater.startDownload`
  的 sha256==null 拒绝闸（android-native update/Updater.kt）。
- 三查端点：`backend/tests/test_update_channel.py`（旧快照冒充最新 → 502 带理由）。

## 发版口径备注（beta 怎么被看见）

- 客户端问的是 `GET /v1/update/info` → 服务端探 GitHub `releases/latest`；
  `releases/latest` **不含预发布**，所以 beta 若标 `--prerelease`，0.22 客户端永远看不到。
  beta 实测窗口内发 tag 时按「非 draft、非 prerelease」发布（与 T3.5 口径一致），
  或明确本跳真机验收直接对正式 0.23 做步骤 2-7。
- 0.22→0.23 这一跳仍需手动装一次最终包（PRD 7.4-6 既定），从 0.23 起全部走应用内。
