# T0.1 · 日程统一界面设计稿说明 + 评审定稿记录

配套文件：`T0.1-日程设计稿-双端同构.html`（浏览器直接打开即两帧对照：安卓手机壳 + 网页桌面壳）。

## 设计决策一句话版

不发明新界面——日程面板从现网设计令牌长出来：`#0b0e15` 深蓝黑底、`#2fbf8f` 薄荷绿（选中/完成/保存主动作）、`#6c7bff` 星紫（有安排的日期标记、dirty 提示），主面板圆角 18、组头 12.5px/letter-spacing .4px、行最小高 54px、编辑框 accent 描边圆角 10（与聊天页 `.edit-box` 同一契约）。识别度来自「时间角标用代码同款等宽字体」这一处签名细节，其余全部克制。

## 同构怎么保证

- HTML 稿里两端共用**同一组 class**（`.sched-panel/.daychip/.item/.group…`），两帧只是外壳（手机壳 vs 侧栏壳）不同；这使"同构"可被 diff 检查而不是口头承诺。
- Compose 对位规则：每个 class 一条注释映射到 `Modifier` 参数（`RoundedCornerShape(18.dp)` 等），色值一律走既有 `Theme.tokens`，**禁止新增色值**——令牌表里没有的颜色不许出现在实现里。
- 唯一允许的平台差异（稿内已标注）：行操作按钮安卓常显 / 网页 hover 显形——沿用 `.msg-tools` 已有的双端规则，不是新决定。

## 结构与状态覆盖

| 区块 | 内容 | 覆盖的 AC |
|---|---|---|
| 顶栏 | 标题 + 完整日期 + 「今天取服务端」注 | R3-AC-3 |
| 日期条 | 周滚动 chip；`days` 字段 → 紫点标记 | R3-AC-1 |
| 清单 | 勾选完成 / 时间角标（可空）/ 编辑 / 删除 / 原地编辑框 | R3-AC-1 |
| 错误条 | 400 → detail 原文直出，不渲染空态（网帧内有示例条） | R3-AC-2 |
| 空态 | 「这天还没有安排」引导添加，与 400 视觉严格区分 | R3-AC-2 |
| 保存条 | dirty 才可点；整天 PUT 幂等；失败保留 dirty 可重试 | R3-AC-1 |

动效基准：进场逐行 stagger（网页 CSS delay / Compose `animateItem()`）、勾选 150ms 变色、日期切换 200ms ease-out。
