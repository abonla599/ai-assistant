## 二、语音输入用例组（R4，T3.1/T3.2 执行）

| # | 用例 | 步骤 | 通过判据 |
|---|---|---|---|
| V1 | 首次授权-允许 | 新装包 → 聊天页点麦克风 → 系统弹窗点「允许」 | 录音态出现，松手出文字 |

## 三、升级实测脚本组（R5，T1.9 执行）

**前提**：GitHub Release 正文含 `APK-SHA256:` 行；后端 `/v1/update/info` 返回 `apk_sha256`。

```text
U-0  装 ai-assistant-native-v0.22.apk（正式签名包），登录，造 3 条会话数据
U-1  设置 → 检查更新 → 出「发现新版本 0.23」+「立即更新」（点击数 ≤3）
U-2  点击下载 → 原生进度对话框百分比滚动 → 完成自动进校验
U-3  校验通过 → 拉起系统安装页 → 安装 → 首启数据全保留（U-0 的 3 条会话仍在）
U-4  断网中断下载 → 残包被清理（adb shell ls 私有目录无 *.apk 残留）→ 重试成功
U-5  篡改：下载完成后（校验前）用 adb 改残包 1 字节 → App 拒装并报明确错误，不进安装页
U-6  劫持模拟：hosts/代理把下载指向异源 URL → ReleasePlan 白名单判 UNUSABLE，拒下
U-7  指纹守卫联动（CI 侧）：故意用新 keystore 出 beta → Release 流水线红（SIGNATURE DRIFT 步骤）
U-8  卸载重装路径确认不再被强制：v0.22→v0.23 覆盖安装成功 = R5 主命题成立
```
