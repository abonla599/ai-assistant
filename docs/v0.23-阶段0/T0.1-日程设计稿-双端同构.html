令牌（双端唯一来源）

--bg #0b0e15 底 · --accent #2fbf8f 选中/完成/保存 · --accent-2 #6c7bff 日期点/dirty 提示
主面板 radius 18、条目 12、编辑框 10；组头 12.5px / .4px；行最小高 54px；时间角标等宽字体（同代码块规格）。
Compose 映射：RoundedCornerShape(18.dp) + 既有 Theme.tokens，不新增色值。

数据契约（后端已就绪）

读取 GET /v1/schedule?day=YYYY-MM-DD → {day, items[{text,at,done}], days[]}；days 驱动日期条上的 #6c7bff 标记点。
保存 PUT /v1/schedule 整天幂等替换（点「保存」才写；离开页未保存要二次确认）。
at 允许为空 = 无固定时间的条目。

状态与异常口径

① 400 → 显示服务端 detail 原文（错误条），不渲染空列表；② 空态 = 「这天还没有安排」+ 添加引导，与 400 视觉严格区分；③ 跨天 → 「今天」永远取服务端返回的 day；④ 保存失败保留 dirty 态可重试；⑤ 加载中日期条禁用，不闪空态。

交互与动效

勾选完成：框体 #242a3a→#2fbf8f 150ms，文本划除；列表进场逐行 stagger（网页 CSS animation-delay，Compose animateItem()）；日期切换横移 200ms ease-out；保存成功按钮旁「已保存」淡入淡出 1.5s。
键盘：编辑框 Enter 保存 / Esc 取消（同 .edit-box 契约）；焦点环 outline: 2px solid var(--accent)。
