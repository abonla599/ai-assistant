# 官网（www.fenever.xyz）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `https://ai.fenever.xyz/` 那段会说谎的 JSON 换成一个单页中文官网,并在自己的子域名 `www.fenever.xyz` 上出得来。

**Architecture:** 官网是 `backend/app/web/site/` 下的一组纯静态文件(一个 index.html、一个 site.css、四张实拍截图)。`GET /` 用 `FileResponse` 出页面,资源沿用已有的 `RevalidatingStaticFiles` 挂在 `/site` —— **不挂根 Mount**(理由见 Task 1 开头与 ledger R7)。域名不加新基础设施,只给现有 Cloudflare 命名隧道多挂一个 hostname。

**Tech Stack:** FastAPI + Starlette StaticFiles、pytest、PyInstaller(冻结版 EXE)、cloudflared、chrome-devtools MCP(实拍)。

**Spec:** `docs/superpowers/specs/2026-09-19-website-design.md`（本计划每条要求都从它出发;两份一起读）

## Global Constraints

- 全中文,单页,零 JavaScript。
- **零外部请求**:不引 CDN、不引网络字体、不引图标库。页面里出现的所有绝对 URL 只允许两个主机:`ai.fenever.xyz` 和 `github.com/abonla599/ai-assistant`。
- **全站不出现 `/admin`**(它是公开的攻击面,不是官网该指的地方)。
- **不宣称「联网搜索」和「代码执行/沙箱」是现成能力**——两条都有证据(DDG 三端点 `curl` 回 `000`;`server.log` 有「⚠️ Docker 不可用,代码执行沙箱暂时停用」)。它们只出现在「当前未开启」一节。
- **不出现「邀请码」作为前置步骤**(v0.11 起自助注册),页面只写「不需要邀请码」。
- **不出现 Flutter / Windows 桌面版 / `Setup.exe` / `C:\Program Files\AI_Assistant`**——`README.md`、`产品说明书.md`、`用户手册.md` 开头那节都已过时。
- 下载入口一律 `https://github.com/abonla599/ai-assistant/releases/latest`,不硬编码 `ai-assistant-0.13.apk` 文件名。
- **APK 体积写「约 96 KB」**。v0.13 的 asset 实测 97835 字节;Release 正文里那句「约 60 KB」是 v0.10 时代的旧数(R8),不要抄它,也不要抄 `产品说明书.md` 里任何体积数字。
- 域名拼写钉死:`ai.fenever.xyz`、`www.fenever.xyz`。`feverver` / `fenerver` 都是错的,写进页面的 URL 一个字母都不能错。
- 测试从仓库根跑:`python -m pytest backend/tests/ -q --tb=short`。CI 按目录跑,**新增测试文件自动进回归**,不用往清单里加行。
- 本机是 Git Bash:`curl -w "/ -> %{http_code}"` 里以 `/` 开头的格式串会被当成路径改写(实测输出成 `C:/Program Files/Git/ -> 200`)。所有 `-w` 串前加 `MSYS_NO_PATHCONV=1`,或把标签写在状态码后面。
- **`git add` 只加本任务点名的文件**。工作树里可能同时有作者另开会话的未提交改动,禁止 `git add -A`、`git add .`、`git commit -a`。
- 演示账号的口令只写在对话里,不进页面、不进文档、不进 git。

## Task 1: 把 `/` 从 JSON 换成官网壳

先让测试变红,再把页面壳立起来。这一步之后 `www` 还没有,但本机 `http://127.0.0.1:8000/` 已经出 HTML,且 `/app`、`/admin`、`/health`、`/docs` 一个都没碰坏。

**这一段的形状是裁决 R7 改过的,照原样做。** 官网**不挂 `app.mount("/")`**,而是:一根 `GET /` 返回 `FileResponse`,静态资源挂 `app.mount("/site", …)`。

为什么不挂根 Mount(两条都是本地复现出来的,不是推测):
1. `Mount("/").path` 是空串 `''` 而不是 `'/'`,而 `test_route_auth_contract._unclaimed_paths` 按 `.path` 算集合 —— 豁免名单里的 `"/"` 盖不住它,契约测试直接红。
2. 根 Mount 会**部分匹配**一切路径,导致 Starlette 的 `redirect_slashes` 不再运行:`/health/`、`/docs/`、`/v1/sessions/` 从 200 变 404,未匹配的 POST 从 404 变 405。`backend/tests/test_auth_endpoints.py:296 test_trailing_slash_cannot_dodge_the_throttle` 钉的正是一条尾斜杠语义 —— 那是安全测试,不能拿它换一个落地页。

代价就是 Step 6 要往 `SYSTEM_PATHS` 登记 `/site` 并写明理由:新开顶层前缀本来就该是一次"显式的、要写理由的改动"(契约测试 docstring 原话),那是设计出来的闸,不是要绕的障碍。

文件末尾追加(照 `_static_dir()` 的形状,冻结版解包路径必须一起处理):

```python
def _site_dir() -> str:
    """官网文件的位置。和 PWA 同层、分目录：它是给人看的一页,不是聊天前端,
    不该被 /app 那份 service worker 的作用域覆盖。"""
    if getattr(sys, "frozen", False):
        base = getattr(sys, "_MEIPASS", os.path.dirname(sys.executable))
        return os.path.join(base, "app", "web", "site")
    return os.path.join(os.path.dirname(os.path.abspath(__file__)), "site")


SITE_DIR = _site_dir()


def site_headers(response):
    """官网两份响应共用一组头:index.html 走 FileResponse,资源走下面那个类。

    不抽出来的话就有第二份 no-cache 字面量,改一份漏一份——和 _PROTECTED_PREFIXES
    在测试里"不抄第二份清单"是同一个道理。
    """
    response.headers["Cache-Control"] = "no-cache"
    response.headers["Content-Security-Policy"] = "frame-src 'none'; object-src 'none'"
    return response


def install_site(app: FastAPI) -> None:
    """官网:`GET /` 出 index.html,静态资源挂 `/site`。

    为什么不是 app.mount("/", ...)：根 Mount 的 .path 是空串,而它会部分匹配一切
    路径,让 Starlette 的 redirect_slashes 不再运行——/health/、/docs/ 一起变 404,
    未匹配的 POST 从 404 变 405。backend/tests/test_auth_endpoints.py:296 钉的正是
    尾斜杠语义,那是安全测试,不该为一个落地页付账。
    """
    @app.get("/", include_in_schema=False)
    async def site_index():
        return site_headers(FileResponse(os.path.join(SITE_DIR, "index.html")))

    app.mount("/site", RevalidatingStaticFiles(directory=SITE_DIR), name="site")
```
