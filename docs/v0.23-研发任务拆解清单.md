## 里程碑与顺序建议

- M1（阶段 0 + T1.1-T1.5）：门禁过 + 更新链路地基。
- M2（T1.6-T1.8 + R1/R2 全部 + R3 双端编码）：功能全量落地。
- M3（T1.9 + 阶段 3）：beta → 真机收口 → 正式发布。

关键路径：T0.1 设计稿 → R3；T1.x 全链 → T1.9。R1/R2 无外部依赖，可最先开工。
估算（不确定性中等）：T1 ≈ 3-4 人日，R1 ≈ 2 人日，R2 ≈ 1.5 人日，R3 ≈ 双端各 2 人日，R4/T3 ≈ 2 人日 + 真机等待。
