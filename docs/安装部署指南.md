# AI智能助手 - 桌面版打包部署指南

## 📋 前置要求

### 必需工具
1. **Python 3.11+**
   ```powershell
   python --version
   ```

2. **Flutter SDK** (已配置Windows桌面支持)
   ```powershell
   flutter doctor
   flutter devices  # 应显示 "Windows" 设备
   ```

3. **Visual Studio 2022** (或2019)
   - 安装时勾选"使用C++的桌面开发"工作负荷

4. **NSIS** (Nullsoft Scriptable Install System)
   - 下载地址: https://nsis.sourceforge.io/Download
   - 安装后确保 `makensis.exe` 在PATH中

5. **PyInstaller**
   ```powershell
   pip install pyinstaller
   ```

## 🛠️ 打包步骤

### 步骤1: 准备环境

```powershell
# 1. 激活Python虚拟环境（如果有）
.\venv\Scripts\Activate.ps1

# 2. 安装依赖
pip install -r requirements.txt

# 3. 确认Flutter Windows支持已启用
flutter config --enable-windows-desktop
```

### 步骤2: 编译Flutter Windows应用

```powershell
# 进入Flutter项目目录
cd flutter_app

# 获取依赖
flutter pub get

# 编译Windows版本
flutter build windows

# 验证输出
ls build\windows\x64\runner\Release\
```

编译完成后，可执行文件位于：
```
flutter_app\build\windows\x64\runner\Release\ai_assistant.exe
```

### 步骤3: 打包Python后端

```powershell
# 返回项目根目录
cd ..

# 使用PyInstaller打包后端
pyinstaller --onedir `
  --name "run_backend" `
  --hidden-import uvicorn.logging `
  --hidden-import uvicorn.loops `
  --hidden-import uvicorn.protocols `
  --hidden-import chromadb `
  run_backend.py
```

打包完成后，输出位于：
```
dist\run_backend\
├── run_backend.exe
├── _internal\          # 依赖库
└── ...其他文件
```

### 步骤4: 准备运行时文件

```powershell
# 1. 复制.env文件到后端目录
cp .env dist\run_backend\.env

# 2. 创建chroma_db目录（如果不存在）
mkdir dist\run_backend\chroma_db

# 3. 复制Flutter编译输出到dist根目录
cp flutter_app\build\windows\x64\runner\Release\* dist\

# 4. 复制启动脚本
cp start_ai.bat dist\
```

最终 `dist` 目录结构：
```
dist\
├── ai_assistant.exe          # Flutter前端
├── start_ai.bat              # 启动脚本
├── run_backend\              # Python后端文件夹
│   ├── run_backend.exe
│   ├── _internal\
│   ├── .env
│   └── chroma_db\
└── ...其他Flutter文件
```

### 步骤5: 测试打包结果

```powershell
# 进入dist目录
cd dist

# 手动测试后端
.\run_backend\run_backend.exe
# （应看到 Uvicorn running on http://127.0.0.1:8000）

# 另开一个终端，测试前端
.\ai_assistant.exe
# （应能看到应用窗口并能与后端通信）

# 测试启动脚本
.\start_ai.bat
# （应先后启动后端和前端）
```

### 步骤6: 制作安装包

```powershell
# 返回项目根目录
cd ..

# 使用NSIS编译安装包
makensis installer.nsi
```

生成的安装包位于：
```
AI智能助手_Setup.exe
```

### 步骤7: 验证安装包

1. 双击运行 `AI智能助手_Setup.exe`
2. 按照向导完成安装
3. 测试桌面快捷方式是否正常启动
4. 测试应用功能是否正常

## ⚠️ 注意事项

### 常见问题

1. **Flutter编译失败**
   - 确认Visual Studio安装了C++桌面开发组件
   - 运行 `flutter doctor -v` 查看详细错误

2. **PyInstaller打包后缺少模块**
   - 使用 `--hidden-import` 添加缺失模块
   - 检查 `run_backend.spec` 文件中的hiddenimports列表

3. **NSIS编译失败**
   - 确认NSIS已正确安装且在PATH中
   - 检查 `installer.nsi` 中的文件路径是否正确

4. **安装包过大**
   - 清理不必要的依赖
   - 使用 `--exclude-module` 排除不需要的模块
   - 考虑使用UPX压缩（`--upx-dir`参数）

### 性能优化

- **启动速度**: 可通过减少Python导入模块数量优化
- **包体积**: 定期清理未使用的Python包
- **内存占用**: 监控后端服务的内存使用情况

## 🔒 安全建议

1. **不要提交 `.env` 文件到Git**
   ```bash
   echo ".env" >> .gitignore
   ```

2. **分发时使用 `.env.example`**
   - 让用户自行填写API密钥

3. **代码签名** (可选)
   - 为EXE文件添加数字签名
   - 避免Windows SmartScreen警告
