## 1. 适用范围

官网 `backend/app/web/site/img/` 下四张实拍图的重截与后续新增实拍图。首批对象为 settings.jpg（本规范主体）与 chat.jpg（署名行口径），register/memory 两张无品牌字样、构图沿用。

## 2. 重截技术参数

| 项 | 值 | 依据 |
| --- | --- | --- |
| 视口 | 390 × 844 CSS px，deviceScaleFactor = 2 | 现图 780×1688，`<img width="780" height="1688">` 不变 |
| 输出 | JPG，sRGB，边长精确 780×1688，体积 ≤ 60 KB | 现四张 43–64 KB 量级 |
| 主题 | 深色（应用默认中性主题），不改任何用户可见主题设置 | 与现图一致 |
| 账户 | 演示账户 `guanwang-demo`，普通用户角色 | 账户名无厂牌信息，保留；它是"演示站"语义的一部分 |
| 数据 | 上下文长度保持默认 10 条；不额外制造数据 | 与 alt 文案不冲突即可 |

## 3. settings.jpg 构图规范（自上而下）

设置面板为全屏 modal，无系统状态栏，截图从面板顶边开始：

1. 标题行「设置」+ 右上 ×
2. 账户卡：头像「g」+ `guanwang-demo` + 绿色「普通用户」徽标
3. 分组「账户」：切换账户（右侧「1 个已登录」)／改密码
4. 分组「模型」：当前模型行，右侧下拉显示 **中性名（见 §5，定稿口径「默认对话模型」）**，保留下拉箭头
5. 分组「对话」：角色设定／上下文长度（10 条 + 滑杆）／导出本次对话
6. 分组「记忆」：长期记忆
7. 分组「设备」：提醒行完整入画，行下方即图片底边（与现图裁切位一致）

DOM 依据：`backend/app/web/static/index.html` :136-200（`#settings` 面板，分组顺序 账户/模型/对话/记忆/设备；「模型服务」行为 admin-only，普通用户截图不出现，无需进二级页）。

## 4. chat.jpg 构图口径

沿用现图构图，仅一处变更：助手消息署名行由「助手 · <厂牌模型 id>」改为 **「助手 · 默认对话模型」**。顶栏「新对话」、用户气泡、demo-note.pdf 附件、正文列表均不动。

**终审拍板①**：现网临时图的「云端模型」不做二次像素修补（过渡词无禁词，二次修补会被重截覆盖=纯浪费）；短期两张图措辞不一可接受，统一放到 F-1g 合并后的重截那批按本节一次到位。

## 5. 中性服务商显示名命名规范

**原则：描述角色与能力，不暴露来源；与全站文案口径一致**（index.html alt 已定稿为「这里选中的是当前默认对话模型」）。

### 5.1 禁词

任何厂牌名、模型家族名、端点痕迹，不区分大小写：`deepseek`、`gpt`、`claude`、`qwen`、`glm`、`doubao`、`kimi`、`moonshot`、`llama`、`gemini`、`openai`、`anthropic`、`api.`、具体域名、`-chat/-base/-instruct` 之类厂牌模型 id 后缀组合。验收以 grep 禁词 0 命中为准。

### 5.2 推荐名集（设置「当前模型」下拉与助手署名共用）

**范围限定（内容运营终审补充，管理员落定）：本节仅约束系统渲染显示名（下拉定稿值、助手署名、营销图 alt 三处逐字一致），不覆盖管理员控制台输入 placeholder——后者守 §5.1 禁词表即可，不必逐字。**

| 角色 | 显示名 | 使用位置 |
| --- | --- | --- |
| 主力对话 | 默认对话模型 | settings 行值、chat 署名（与 alt 逐字一致） |
| 轻量快速 | 轻量对话模型 | 多模型演示时的第二项 |
| 视觉理解 | 视觉模型 | 涉及图片问答演示 |
| 本机推理 | 本地模型 | 飞行模式/本地演示场景 |

命名格式统一为「<能力/定位> + 模型」，4–6 个汉字，不带版本号、不带破折号/连字符 id 样式。

### 5.3 配置入口

管理员在设置 → 模型服务 → 新增服务商的「显示名称」字段填写（`index.html` :270）。**重截必须跑在 F-1g 合并后的构建上**：当前 develop 该字段 placeholder 仍为「例如 DeepSeek Chat」，F-1g 分支已清（管理员 grep 0 命中核实）；合并前该页面任何入画区域都不得出现在截图中。

**终审拍板② + 补充（内容运营）**：admin 表单三个 placeholder 纳入 F-1g 合并前最后一批中性化，与 :185 OPENAI-COMPLETION 同批，归前端：
- :270 显示名称 → 「例如 默认对话模型」
- :271 Base URL = `https://api.deepseek.com/v1`（命中 §5.1 禁词 api.+deepseek）→ 占位域示例如 `https://api.example.com/v1`
- :273 模型名 = `deepseek-flash / qwen-vl-max`（命中 deepseek+qwen）→ 无厂牌格式样例如 `chat-default / vision-default`

虽为 admin-only 不入画，但与 probe.html 同类 = 公网可取的已服务 HTML 泄露面，§5.1 禁词表要求同批处理方自洽。

## 6. 执行与验收清单

1. 前提：F-1g 已并入 develop，本地实例起服务。
2. 按 §5.2 在演示账户配置 provider 显示名，刷新确认下拉与署名渲染为中性名。
3. 按 §2 视口参数截图，settings 按 §3、chat 按 §4 构图。
4. 验收：尺寸精确 780×1688；100% 放大目检无厂牌文字/图标/logo（含输入法候选、URL 栏、图片元数据注释）；体积 ≤60 KB；图内模型显示值与 alt 中的模型名逐字一致（alt 全文「…这里选中的是当前默认对话模型」中，「当前」修饰选择动作，行值本身为「默认对话模型」）；grep 禁词 0 命中（对截图工程配置与产物目录）。
5. 替换 `backend/app/web/site/img/` 两图并提交，同时知会内容运营复核上线页。
