# 智能体系统说明文档

## 1. 系统概述

智能体模块实现了任务规划-执行-汇总的完整闭环，能将复杂任务自动分解为子步骤并逐一完成。

## 2. 整体架构

用户请求 → Orchestrator（协调器）
              ├── Planner（规划器）：用 LLM 分解任务
              ├── Executor（执行器）：调用 TaskAgent 逐步执行
              └── 汇总：整合最终答案

## 3. 核心组件

| 组件 | 文件 | 功能 |
|------|------|------|
| Orchestrator | app/agents/orchestrator.py | 协调整个任务流程，支持取消 |
| Planner | app/agents/planner.py | 用 LLM 分解任务为子步骤 |
| Executor | app/agents/executor.py | 执行单个子任务 |
| TaskAgent | app/agents/task_agent.py | 单智能体，循环调用工具 |
| task_store | app/agents/task_store.py | 任务状态管理和存储 |

## 4. 任务状态机

PENDING → RUNNING → COMPLETED
              ↓
          FAILED / CANCELLED

## 5. API 接口

### 创建并执行任务
POST /v1/agent/orchestrate
{ "goal": "任务描述", "task_id": "可选" }

### 查询任务状态
GET /v1/tasks/{task_id}

### 取消任务
POST /v1/tasks/{task_id}/cancel

### 列出所有任务
GET /v1/tasks

### 删除任务
DELETE /v1/tasks/{task_id}
