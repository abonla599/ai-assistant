## 3. 规格内的唯一有意偏差 + 两处原生侧加固（T2.2 范围内）

1. **流式中编辑置灰（PRD R1 边界条款明令，网页反而没有）**：核对确认网页 `onTool`/
   `editMessage`/`regenerate` 不检查 `state.streaming`——原生按 R1 要求把
   编辑/保存/重新生成在流式中置灰（字色淡一档、不吃点击、位置不动）。
   这是 AC 对原生的显式要求，不视为 S1 差异，建议 T3.4 终审按本记录签认。
2. **AC-3 断网提交不丢编辑内容**：网页靠「commit 里 await 抛错就不重渲染」天然保住
   编辑框；原生改为**先落服务端、失败退回编辑态且草稿保留**（editingDraft 提升到父侧），
   行为与网页等价、判据更明确。
3. **7.1-4 会话被其他端删除（404）**：原生 persist 捕获 404 → 提示「这个会话已在其他端
   被删除，已为你刷新」+ 清会话回空态 + 重拉列表。网页端该场景无专属处理（S1 待议项，
   非本版本范围，仅记录）。
