# v0.14（2026-09-20）

这一版主要是**让安卓 14 的手机能打开助手**。上一版在部分新机器上点图标闪一下就回桌面，
根本没进到界面 —— 已定位到原因并修好，但**这台机器我们手上没有**，
所以这条要装了这个包的人帮忙确认。

## 修复

- **安卓 14 秒退**：壳在启动时注册一个下载完成的通知，没按新系统的要求声明"这个通知实不
  对外公开"，于是新系统直接把这个应用判死。现在补上了，并且钉了一条源码级检查，
  防止以后再有同样的写法混进来。
- **分享文本进助手**：从别的 App 分享一段纯文字时，以前经常被判成"没有内容"直接丢掉，
  等于清单里那条声明白写。现在文字也能挂到附件栏。
- **拒收不再沉默**：太大的文件、太长的文本、不收的格式，以前是"点了没反应"。
  现在页面上会写清楚为什么没收下。

## 优化

- **登录界面开场**：字标先站住，等表单真的画到屏幕上了再掀开那块弧形面板。
  每次冷启动播一遍；系统开了"减少动态效果"就整段不放。
- **首帧不再闪一下聊天界面**：以前会先看到对话外壳、再跳到确认身份那一层。
  现在第一帧就是确认身份，不会先把不该露的露出来。
- **长按图标的快捷方式加了兜底**：系统读不出静态配置时，自动补上等效的动态快捷方式。
- **改了系统日期或时区**，桌面组件的"今日"会跟着换。
- **对话里的模型现在能真的动手**：流式回答接上了工具调用（此前只有非流式那条路有），
  问它算数、查东西，它是去调用而不是凭记忆猜。

## 装完麻烦帮忙看这几条

上面带"没实机验过"性质的，都在这 14 条里 —— 本机没有安卓真机，
这些是**只有你的手指能给的证据**：

1. 设一条 2 分钟后的提醒 → 锁屏出通知，标题正文与设置一致
2. 通知点进去 → 直接落在助手界面，且不是重新登录
3. 设一条每天重复 → 触发后第二天时间已推进，不是消失
4. 手机重启 → 那条提醒还在且会响
5. 相册里选一张图 → 分享 → 出现"AI 助手" → 点开后进 App 且附件栏已挂着那张图
6. 分享一张 >10MB 的图 → 有明确拒绝提示，不是静默没反应
7. 桌面组件显示今日提醒；换到另一个账号登录 → 组件里看不见上一个账号的提醒
8. 手机浏览器直接开 `https://ai.fenever.xyz/app/` → 一切照旧，提醒栏出说明文案，无报错
9. **装的时候先不要卸载旧版**：覆盖成功且口令与提醒都在 → 以后换包零代价；
   提示签名冲突 → 请回来说一声，我们得在说明里写清"要先卸载、口令需重填"
10. 从别的 App 分享一段**纯文本**给助手 → 附件栏出现一个小文件、内容就是那段文字
11. 分享一段超过 1MB 的文字 → 网页顶栏出红字「分享没收下：这段文本太长」
    （看到 Toast 也算通过，但请记下你看到的是哪一个）
12. 长按桌面图标 → 两条快捷方式都在且点得动，点进去落到对应界面
13. 手动改系统日期或时区 → 桌面组件的"今日"跟着换
14. 在助手里下载一个附件 → 有没有"已保存"的提示（这一版把那个通知改成了不对外公开，
    个别机型可能因此收不到完成通知；文件本身照样会下载，只是少了那一声提示）

哪条查出来是假的，回来说一句，我们改文档而不是留着"应该没问题"。
