# v0.19（安卓）

## 修了什么

- 【装包才生效】**「检查更新」被系统下载器劫持**：以前壳把下载地址交给系统的
  DownloadManager，部分 ROM 会把它转给第三方下载通道（实测见过"迅雷正在加速"），
  通知栏里名字变成"未命名"，下完是个残包，点开只会报"安装失败"。
  现在整条更新链路都在壳自己手里：向助手服务器问版本（不再直连 GitHub），
  下载由壳自己完成，通知栏不再出现第三方通道，也不再有任何浏览器/下载器参与。

## 优化了什么

- 【装包才生效】**"问不到" 与 "已是最新" 从此是两句话**：更新检查改走助手自己的
  服务器，服务器拉不到发布页时回的是带理由的失败，壳会照实说"问不到发布信息"，
  不再有可能被误读成"你没有更新"的沉默。

## 加了什么功能

- 【装包才生效】**应用内更新，带进度条**：点「检查更新」发现有新版，确认后直接在
  壳内下载，对话框里显示真实进度（字节数与百分比），下完自动弹起系统的安装页。
  中途不离开壳，不再出现"未命名"那种看不懂的下载通知。
- 【装包才生效】**安装前先核对指纹**：每个正式发布的 Release 正文里带一行
  `APK-SHA256: …`（发布流水线在签名之后算好写进去）。壳下载完会自己算一遍摘要，
  **对不上就没有任何安装页会被拉起**——半截包、被换过的包、来源不明的包一律拒装，
  并且明说是哪一种原因（问不到校验值/下载中断/指纹不一致）。

## 装完麻烦帮忙看这几条

1. **别卸载**，覆盖安装即可（v0.17 起同一把签名；如果手机上还是 ≤v0.16 的旧包，
   那才需要先卸再装一次）。
2. 这一版就是走新链路发出来的：装完后点「检查更新」，应当直接回"已是最新"。
3. 等下一个版本发布时点「检查更新」：确认弹窗 → 进度条从 0 走到满 → 自动弹系统安装页，
   全程通知栏里不该出现任何第三方下载通道的影子。
4. 有兴致的话看看 Release 页正文最后一行：那 64 位十六进制与本地文件算出来应当一致。
