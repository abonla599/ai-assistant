# v0.17（2026-09-21）

这一版最重要的事跟功能没关系：**安装包从此签在一把固定的密钥上**。
以前每次发版是 CI 现场生成一把调试密钥，v0.15 和 v0.16 的证书因此不是同一把，
安卓判定"这不是同一个应用"，于是覆盖安装被拒——报的是"标签不一致/签名不一致"，
跟版本号一点关系也没有。

所以这次装要**先卸载旧的再装**，一次性代价。卸之前不用备份什么：口令、会话、
长期记忆都在服务器上，装完用自己的用户名密码登录一次就都回来了。
从 v0.17 往后，同一条签名链之间可以直接覆盖安装。

## 修了什么 bug

- 【装包才生效】**更新装不上**：根因是签名不是版本号，见开头那段。这一版起改成
  固定的发布密钥；CI 拿不到那把密钥时**直接失败**，不会悄悄退回调试签名再发一份
  装不上的包。
- 【不用重装】**自带模型探测页跑到第四项就不动了**：以前"卡住"没有尽头。现在每一项
  自己带超时（20 秒），到点自己报"超时"并接着往下跑，跑完给你一份能读的汇总。
- 【不用重装】**设置里"我的版本"显示的是"网页版"**：那一行现在会去问服务器
  "你是第几版"，壳与服务端各是多少都写出来。网页界面本来就没有版本号——
  它随服务端一起更新，不需要你重装。
- 【不用重装】**官网那四张实拍在手机上看不见**：不再压半透明。
- 【不用重装】**用量看板上没有入口**：管理页 `/admin` 多一个「用量」分区，
  谁用了几次、多少 token、钱是谁出的，一天一张表。以前这些只能手敲 curl。

## 优化了什么

- 【不用重装】**工具输出发给模型之前按预算截断**，并且写明截掉了多少字。
  静默截断比截断更糟：模型会以为它看到的是全貌，然后理直气壮地基于半截日志下结论。
- 【不用重装】**长期记忆不再"每轮存前 200 字"**：只有四类话进库——你明确交代的、
  对它的纠正、你自述的身份与长期偏好、你报的学习进度。普通的一次性提问不再制造
  检索噪声（那样库里全是"帮我改一下这句话"，真该想起来的反而被挤掉）。
- 【不用重装】**`/health` 从"进程还在吗"升级到"东西齐不齐"**：模型服务、密钥库、
  用量账本、记忆后端、限流账、数据落点六项各自体检，顺带报一句自己是第几版。
- 【不用重装】**登录/注册/找回密码的限流判据收紧**：只有请求确实从本机隧道进来，
  才认 Cloudflare 写上的来源地址。以前任何能直连源站的人伪造那个头，就能对任意账号
  无限重试。
- 【不用重装】**CI 多了一道密钥扫描**：把密钥形状的字符串提交进仓库会直接红，
  不再只靠"记得别提交"。
- 这一版新增一百多条回归测试（现在 756 条），每条都做过"把行为改坏、看它是否真的变红"
  的验证——只查"有没有这个函数"的测试不算锁。

## 加了什么功能

- 【不用重装】**日程**：聊天里说一句「明天下午三点开组会」，它记进**你自己**的日程；
  哪天想不起来要干什么，问一句「今天该干什么」它就念回来。存在服务器上，
  换手机、卸载重装都还在。两件边界说在前面：
  - 它**不会主动弹通知**——服务端没有任何给你发消息的通道，只有你问它才答。
  - "它会不会主动帮你记"取决于上游模型肯不肯调这个工具，**这条还没在真机上验过**。
    所以麻烦你验一下（下面第 3 条），答不出来是这次最要紧的反馈。

## 装完麻烦帮忙看这几条

1. 先卸载旧版再装 v0.17（不卸会报签名不一致，这是预期内的），装完登录一次，
   看看会话与记忆还在不在
2. 设置 → 设备 那一行显示的是不是 `v0.17`
3. 聊天里说「明天下午三点开组会，记一下」→ 再问「今天该干什么」，它答得出来吗
4. 打开 `https://ai.fenever.xyz/site/probe.html` 跑一遍，把报告发我
   （上一版卡在第四项的那个问题，这次每一项都该有结果）
5. 下一版（v0.18）出来时**别卸载**直接覆盖装，看还报不报"标签不一致"——
   这条才是这次签名改动的真正验收
