# v0.21（安卓）

> 这个 APK 仍是**网页版壳**：界面就是 https://ai.fenever.xyz 上的网页本体，
> WebView 直接加载，不做任何原生复刻。本版只把壳的版本号对齐到 v0.21，
> 让「检查更新」看到的版本与服务端「设置 → 关于」报的是同一个数。

## 修了什么

- 本版壳客户端代码无改动，无修复项。

## 优化了什么

- 【仅版本号】versionName / versionCode 对齐服务端 0.21 节奏，
  避免「设置 → 关于」与「检查更新」两处版本号长期不一致引起误判。

## 加了什么

- 【试用，独立安装包】新增**原生 Android Beta**（另一份 APK，
  `ai-assistant-native-0.21-debug.apk`）：主体用 Compose 原生实现聊天、会话、
  记忆与设置，包名与壳不同，两者可共存安装。原生版仍在打磨，网页壳继续作为
  与网页 1:1 的正式入口保留。
