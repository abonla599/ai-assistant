# v0.21（安卓原生）

> 从本版起，GitHub 推送版只发**原生 Android 客户端**：主体用 Compose 原生实现
> 聊天、会话、记忆与设置，直接对接 https://ai.fenever.xyz 的服务端 API。
> 旧的 WebView 壳不再随发行版推送；**网页版长期保留**，浏览器打开
> https://ai.fenever.xyz/app/ 即可使用。装过旧壳或原生 debug 包的用户，见文末安装注意。

## 修了什么

- 创建新会话报「method 'POST' must have a body」：原生客户端对空 body 的
  POST 统一补空 JSON body，会话创建/导出票据/模型连通性测试恢复正常。
- 改密码（找回密码）流程：点系统返回键或卡片右上角 × 现在能正确回到上一步；
  重置成功后自动登录就地续用，删掉了多余的「回去登录」入口。
- 输入框：点击建议标语后光标落到句尾（原先跳回句首）；占位文案改为
  「发消息或按住说话」，不再提示手机端用不了的 Shift+Enter。

## 优化了什么

- 设置弹层铺满全屏高度；登录卡片在窄屏/横屏下垂直居中。
- 补齐真实应用图标：桌面 launcher 图标与应用内品牌标同源。

## 加了什么

- 【安装注意】推送版正式切换为原生 APK（`ai-assistant-native-0.21.apk`），
  与网页版 https://ai.fenever.xyz/app/ 账号数据完全互通。
  若你装过本仓之前发的 debug 包或旧 WebView 壳，本次需**卸载后重装一次**
  （签名从 debug key 换成了钉定的正式 key，覆盖安装装不上）；
  此后版本更新可直接覆盖安装。
