# v0.20（安卓）

> 本版修复全部在**助手服务器**（https://ai.fenever.xyz ）上完成，已上线生效；
> 这个 APK 里没有新增客户端代码，只把壳的版本号对齐到 v0.20，
> 让「检查更新」看到的版本与服务端「设置 → 关于」报的版本是同一个数。

## 修了什么

- 【服务端，装不装都生效】**聊天偶发 502**：后端打包时混进了一份 2019 年的老
  VC 运行库，触发记忆检索时原生崩溃。已换用系统现役版本并加了两道产物锁。
- 【服务端，装不装都生效】**发消息后对话框长时间"生成中"不回应**：记忆嵌入的
  上游接口挂起时，聊天会陪着干等两分多钟。现已给该调用加 10 秒快断——最坏情况
  降级为"本次不带记忆"，聊天照常秒回。

## 优化了什么

- 本版客户端无独立优化项：所有改动随上面的服务端修复生效。

## 加了什么功能

- 本版无新增客户端功能。
