# v0.18（2026-09-23）

这一版只为了一句话：**「我设过的提醒从来没响过」**。

查下来代码里那四条路都是通的：闹钟确实排进去了、时间换算没错、通知渠道建了、权限也确实问过。
剩下两种可能都只发生在手机上：**要么通知授权没给**（而以前这一支是一句直接丢弃，连一笔都不记），
**要么省电策略把到点的广播拖到几小时之后**。这两种在屏幕上长得一模一样，所以这一版不去猜，
而是让两种都读得出来，同时把"精准闹钟"这个开关要过来。

## 修了什么 bug

- 【装包才生效】**到点没响的提醒在屏幕上不留痕迹**：通知没授权时闹钟照样走到点，
  但那一步以前什么都不写。现在它给这一条记一笔"到点没发出"，提醒那一行会写出来。
  边界说在前面：**记一笔不等于补发**——`once` 那条错过就是错过了，这一版故意不做补发。
- 【装包才生效】**排期只有"可能晚几分钟"这一档，而看不出是哪一档**：现在申请
  `SCHEDULE_EXACT_ALARM`（Android 12 及以上要在系统设置里给）。给得了就走准点那一档，
  给不了仍按老办法排——**不会因为没授权就把这条提醒丢掉**。
- 【不用重装】**网页版打开要等很久**（有时接近一分钟）：首屏那十几趟回源压成两三趟，
  静态资源按版本盖水印给一年长缓存，页面自己报是哪一版、发现是旧版会自己跳一次。
  本机实测重复打开从 1.88 秒降到 0.29 秒；手机上还得你复验一次。
- 【不用重装】**联网搜索出不来结果**：换一个在这台机器上出得去的源；"通不通"的判据也从
  "端口开得起来吗"改成"真发一条查询看看"。
- 【不用重装】**结果一片噪声时它照着答**：返回的条目里一条都不含你这句查询的关键词时，
  现在会附一句提醒它别硬答。
- 【不用重装】**它不知道今天是哪天**：涉及日程的对话从此带着当天日期与星期。
- 【不用重装】**有些界面返回键是"直接退出应用"**：改成退一层。

## 优化了什么

- 【装包才生效】**提醒页顶部多了一行常驻状态**：通知授权给没给、当前排的是准点还是省电那一档，
  每条提醒还带着"上次什么时候真发出去了、几次到点没发出"。读不到的时候明说读不到——
  这一行不许有一格是靠猜填上的。
- 【装包才生效】两颗「去设置」直达系统那一页。打不开时会说"打不开"，而不是点了没反应。
- 【不用重装】服务器给每个请求记一行"什么时候到的、花了多久"，慢的那几行标出来。
  下一次再出现"打不开"，先有的就是证据而不是猜测。
- 这一版周期内新增一百二十多条回归测试（现在 884 条），每条都做过"把行为改坏、
  看它是否真的变红"的验证——只查"有没有这个函数"的不算锁。

## 加了什么功能

本版没有新的用户可见功能：上面那一行状态与两颗入口就是全部。
准不准点这件事**还没在真机上验过**，所以这里不写"提醒从此准点"。

## 装完麻烦帮忙看这几条

1. **别卸载**，直接覆盖装 v0.18（v0.17 起是同一把签名，装了卸不掉的那次是历史代价）。
2. 设置 → 设备 → 提醒：那一行现在写的是什么？（通知那一格、闹钟那一格各照原话发我）
3. 设一条两分钟后的提醒，**锁屏等它响**。响了之后那一行是不是变成"上次发出 月/日 时:分"，
   以及它比预定时间早了还是晚了多久。
4. 通知授权先关掉，再设一条到点的：看它是不是记成"1 次到点没发出"。
   这一条能证明那个痕迹是真的，而不是界面写的漂亮话。
5. 网页版重复打开还要不要等（浏览器里、壳里各试一次）。
