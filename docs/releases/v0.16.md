# v0.16（2026-09-20）

上一版把「检查更新」只放在长按图标的快捷方式和桌面组件上，结果**没人找得到它**——
第一反应都是去设置里翻。这一版把它挪进 **设置 → 设备**，并且让那一行显示你这台手机
装的到底是哪一版。

**这一行不用重装就能看见**（它是服务器上那张页面画的）；但要它点下去真的去查，
得装到 v0.16。装不到的人点它会打开下载页——不会是一个点了没反应的空按钮。

## 修了什么 bug

- 【装包才生效】**看不出自己装的是哪一版**：应用里以前根本没有版本信息，
  只能去安卓系统设置 → 应用 → AI 助手 里翻。现在设置 → 设备 那行右边直接写着
  `v0.16`，v0.14/v0.15 上则写着「当前版本 · 去下载页」。
- 【不用重装】**这一行在旧壳上差点变成死按钮**：旧壳的桥里没有 `checkUpdate`
  这个方法，无条件调用的结果是点一下什么也不发生、页面连一句错都不显示。
  现在这一行的去向由壳上报的能力标志决定，认不到就走下载页那条退路。
- 【不用重装】**手机浏览器里不该出现这一行**：那里没有"安装包"可更新，
  界面本来就是打开即最新。现在没有壳的时候整行藏掉。

## 优化了什么

- 【装包才生效】**三条入口合成一条路**：长按图标的快捷方式、桌面组件那颗按钮、
  设置里这一行，现在都调同一个入口去查。上一版长按与组件是同一条，但网页这条路
  是新开的——分开写就会有一天只改对一边。
- 【装包才生效】**壳把自己的版本号报给页面**（能力清单里多两项：认不认检查更新、
  装的是哪一版），页面不再靠猜。

## 加了什么功能

- 【不用重装 + 装包才生效】**设置 → 设备 → 检查更新**：
  - 装了 v0.16：点下去与长按图标那条完全一样——问一次最新发布版，有新版先弹确认框，
    你点「下载」才开始动流量，下完自动弹起系统的安装页；查不出结果会说清是连不上
    还是别的，不会把"检查失败"报成"已经是最新版"。
  - 装在 v0.14/v0.15：点这一行打开下载页，在那里拿新的 APK。
  - 手机浏览器：这一行不出现。

  不变的还是那句：**不点它就不会拿到新安装包**。没有任何自动检查——
  开机、进后台、刷新桌面组件都不会去问服务器，这条现在还被测试钉着。

## 装完麻烦帮忙看这几条

我们手上没有安卓真机，这些**只有你的手指能给出证据**：

1. 装 v0.16 后 → 设置 → 设备 有没有「检查更新」，右边是不是 `v0.16`
2. 点它 → 出不出"正在检查更新…"和后面的对话框（内容应与长按图标那条一模一样）
3. 手上还是 v0.15 的话 → 这一行右边是不是写着「v0.15 · 去下载页」，点了**真的**打开下载页
   （最怕的就是这一条：点了没反应，那说明退路没接上）
4. 手机浏览器开 `https://ai.fenever.xyz/app/` → 设置 → 设备 里**不该**有这一行
5. 长按图标的三条快捷方式、桌面组件的三颗按钮都还在、都点得动（这次改动不该碰到它们）
6. **覆盖安装**（先别卸旧的）：口令、提醒、会话都还在吗？
   这条从 v0.14 一直欠着答案，它决定以后发版要不要写"必须先卸载"
7. 图片与 Word 还读得动吗（上一版修好的东西，这次没碰服务端逻辑，但顺手确认一下最省）

哪条查出来是假的，回来说一句，我们改文档而不是留着"应该没问题"。
