# v0.15（2026-09-20）

这一版做两件事：**发出去的图片和 Word 文档真的能被读出来**，以及**软件里多了一颗
「检查更新」按钮** —— 不点它，就永远拿不到新的安装包。

第一条不用重装：它改的是服务器上的配置与解析代码，你下次打开助手就已经是好的。
第二条必须重装：那颗按钮长在壳里，网页替不了它。

下面每条都标了**要不要重装才生效**。

## 修了什么 bug

- 【不用重装】**发图片只会收到一句「当前模型不支持图片输入」**：这句是配置里
  `supports_vision=false` 挡下来的，不是模型不行 —— 拿真截图直接打上游，
  它把图里的文字逐块读了出来。默认模型换成实测能吃图的那一个（`deepseek-flash`），
  闸门跟着打开。现在发截图问"解读一下"，它真解读。
- 【不用重装】**Word 文档传不上去**（「不支持的文件类型 .docx」）：上传白名单里
  只有 PDF。现在 `.docx` 能传，正文与**表格单元格里的字**一起读得到
  （实验数据常放在表里）。
- 【不用重装】**老 `.doc` 与改了扩展名的 Excel 只回一句「打不开」**：现在各给一句
  照着做就能走通的话 —— 老格式提示"另存为 .docx"，xlsx/pptx 改名来的提示
  "这份文件里没有正文"，设了打开密码的提示"请去掉密码再传"。
- 【不用重装】**上传的 Word 是一个攻击面**：文档里的 XML 由用户上传，之前直接交给
  解析器。现在声明了 XML 实体/DTD 的一律拒（那种构造能把你机器的内存吃穿），
  解压体积也封了顶（原始文件不到 10MB、解压后几十 MB 的那种"炸弹"）。
  正常用 Word/WPS 写出来的文档不受影响。
- 【不用重装】**官网有一行现在是谎**：页面上写着"这台服务器上唯一标着支持图片的那条
  模型，密钥还填着占位符，所以发图片只会得到一句拒绝"。这句话今天已经不成立，删了。
- 【不用重装】**设置页「模型名」的示例写着一个已经不在清单里的名字**：
  上游现在只列 `deepseek-flash` 与 `deepseek-v4-pro`，示例还挂着 `deepseek-chat`。
- 【不用重装】**新机器上的默认配置与线上不一致**：首次启动播种那份和预置模板
  还写着旧的模型名和"不支持图片"。现在三处同一个口径。

## 优化了什么

- 【装包才生效】**长按图标的快捷方式从两条变三条**，桌面组件也多一颗按钮。
  系统读不出静态配置时，兜底那条会一并把缺的补上（以前只兜两条）。
- 【不用重装】**换模型不再需要两处一起改**：界面显示的名字、真正发出去的模型名，
  现在来自同一份配置。

## 加了什么功能

- 【装包才生效】**「检查更新」**：长按桌面图标 →「检查更新」，或者点桌面组件上那颗。
  它会去问一次最新发布版，然后：
  - 已经是最新 → 告诉你"已经是最新版 v0.15"；
  - 有新版 → 先弹一个框写清"当前 v0.15 → 最新 v0.16，约 XX KB"和这一版的说明，
    **你点「下载」它才开始动**；下完自动弹起系统的安装页；
  - 问不出结果 → 说清是连不上还是发布页形状不对，**不会把"检查失败"报成"已经是最新版"**。

  两件事要说在前面：① **不点它就不会拿到新安装包**，这是这个功能的全部意义；
  ② 聊天界面本身仍然是打开就是最新的一版（它在服务器上），这颗按钮管的是
  壳自己的原生能力（提醒、分享、组件、检查更新）。

## 装完麻烦帮忙看这几条

我们手上没有安卓真机，下面这些**只有你的手指能给出证据**。

只列这一版新增的与最要紧的几条：

1. 长按桌面图标 → 有没有第三条「检查更新」？点它 → 出"已经是最新版 v0.15"
2. 只有两条的话：那条快捷方式点了没反应，还是桌面凭空多出两条重复的？
   （前者说明静态配置又被系统忽略了，后者说明兜底判据判错 —— 两种都是 bug，请回来说一声）
3. 桌面组件上那颗「检查更新」点得动吗？出的是同一个对话框吗？

6. 没给过"安装未知应用"权限时：出的是"去设置"那个框，还是什么都不发生
7. **装的时候先不要卸载旧版**：覆盖装成功且口令、提醒都还在 → 以后换包零代价；
   提示签名冲突 → 请回来说一声，我们得在说明里写清"要先卸载、口令需重填"
8. 发一张图片问"解读一下" → 它读得出图里写了什么（这条不用重装也该好，装了就一并确认）
9. 传一个 `.docx` → 不再报"不支持的文件类型"，正文和表格里的字都读得出来
10. 传一个老 `.doc` → 提示里有没有"另存为 .docx"这句
11. 手机浏览器直接开 `https://ai.fenever.xyz/app/` → 图片和 Word 照读，
    且**不会**看到「检查更新」那颗按钮（浏览器里没有壳，本来就该看不到）
