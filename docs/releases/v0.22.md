# v0.22（安卓原生）

> 本版起输入框的「发消息或按住说话」是真的能按住说话：空输入框上长按即录音，
> 松手把识别出的文字直接发出，按住时向上滑可取消。网页版同版本上线了同一功能。

## 修了什么

- 无。

## 优化了什么

- 无。

## 加了什么

- **按住说话（语音输入）**：聊天输入框为空时，长按说话区触发系统语音识别，
  边说边上屏（浮层里有实时波纹与转写预览）；松手发送识别结果，上滑进取消区、
  再松手即取消。首次使用会申请麦克风权限；设备没有系统语音服务时会在状态条
  说明，不会静默失败。
- 录音浮层：底部蓝色穹顶 + 音量波纹条 + 「松手发送，上移取消」提示，
  取消区为红色态，与网页版同款交互。
