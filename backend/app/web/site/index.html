AI 智能助手

一个你自己注册就能用的助手。它记得住你说过的事,能算数,能读你发过去的文件,每个人各用各的、互不串味。

网页版 装安卓壳（约 96 KB）

不需要邀请码,不需要填 API 密钥。用户名密码自己定,注册完就能聊。

它现在真能做的

  • 多模型切换

    在现在可用的那几个模型之间换着用。清单和各自能用几条都写在设置那一格里,默认用哪个由服务端定,你不用配任何东西。

  • 会算数

    让它算数,它走计算器,不是自己心算:表达式在本机按 AST 白名单解析,不会原样执行模型给来的字符串。65 位的 50! 就是这么算出来的。

  • 读你发过去的文件

    发 PDF、Word（.docx）、txt 或代码文件,它先把里面的文字读出来再回答,不用你抄一遍。图片要当前模型带视觉才行:默认那条带,截图发进去读得出图里的字;换成不带视觉的模型就会明确拒绝,不会硬答。

  • 长期记忆

    你说过的偏好存成语义可检索的记忆,聊到相关的地方它会想起来。存了哪些,你在设置里能看到、能删。

  • 多人各用各的

    会话、附件、记忆都挂在你这个账号上。别人看不到你的,你也看不到别人的。

装壳多出来的三件事

这三件要装那个 96 KB 的壳才有,浏览器拿不到系统通知、分享入口和桌面组件。壳只是一个指向本站的地址,不含口令也不含密钥,所以服务端改版不用重装;改壳的这三项才要重装。

  • 提醒

    设置 → 提醒。到点弹系统通知,手机重启后依然生效。提醒只存在这台手机上,不上传服务器。可能晚几分钟,它不申请精确闹钟权限。

  • 分享进来

    在相册或 PDF 上点「分享」,选「AI 助手」,文件直接挂到附件栏,不用先存再传。挂上去只是第一步,读不读得动仍要看当前模型带不带视觉。

  • 桌面组件

    主屏放一个小组件,显示今天的提醒,两个按钮直达拍照提问与新对话。拍照提问也要模型带视觉才读得出图。

三步上手

  1. 打开 ai.fenever.xyz/app/（或装上面那个壳,它自动跳到同一个地址）。
  2. 注册:在登录页切到「注册」,填用户名、密码,再答三条固定的找回问题,忘记密码时拿它自己取回。
  3. 开始聊:换手机换设备,用同一个用户名再登录一次,记录和记忆都在。

看到「当前没有可用模型,请联系管理员配置模型服务」,那是这台助手的主人还没接上模型,找他,跟你的账号无关。

常见问题

要自己配 API 密钥吗?

不用。模型由这台助手的管理员配,普通人什么都不用填。

换手机 / 重装 App,记录会丢吗?

不会丢。聊天记录、附件、长期记忆都在服务器上你这个账号里,用同一个用户名再登录一次就回来。提醒存在旧手机本机,不跟着账号走。

谁能看到我的数据?

只有你。会话、附件、记忆按账号隔离,别的注册用户看不到你的。

怎么删干净?

设置里删会话与记忆条目。要注销整个账号,联系这台助手的管理员做删除;记忆库里哪些会一起被抹掉,删之前当面问清。

有 iOS 吗?

没有壳,但 Safari 打开 ai.fenever.xyz/app/ 一样能用,加到主屏幕后接近全屏体验,只是没有提醒、分享入口和桌面组件。

打不开怎么办?

这台助手跑在一台个人电脑上。机器关机、断网,或者重启后没人登录,它就会暂时够不着。那不是你的账号出了问题,等一会儿再试。
