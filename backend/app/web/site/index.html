AI 智能助手

一个你自己注册就能用的助手。它记得住你说过的事,能算数,能读你发过去的文件,而且每个人各用各的、互不串味。

网页版 装安卓壳（约 96 KB）

不需要邀请码,不需要填 API 密钥。用户名密码自己定,注册完就能聊。

它现在真能做的

  • 多模型切换

    同一个助手里换着用当前可用的模型——清单和「能用几条」都写在设置那一格里,默认用哪个由服务端定,你不用配任何东西。

  • 会算数

    让它算数,它走计算器而不是自己心算:表达式在本机按 AST 白名单解析,不会原样执行模型给来的字符串。65 位的 50! 就是这么算出来的。

  • 读你发过去的文件

    发 PDF、Word（.docx）、txt 或代码文件,它会先把里面的文字读出来再回答,不用你抄一遍。图片走的是另一条路:当前默认模型带视觉,截图发进去它读得出图里的字;换成一个不带视觉的模型这条路就断,那时会明确拒绝而不是硬答。

  • 长期记忆

    你说过的偏好存成语义可检索的记忆,聊到相关的地方它会想起来;哪些记忆在存着,你在设置里能看到、能删。

  • 多人各用各的

    会话、附件、记忆都挂在你这个账号上。别人看不到你的,你也看不到别人的。

装壳多出来的三件事

下面这三件只有装了那个 96 KB 的壳才有——浏览器拿不到系统通知、分享入口和桌面组件。壳本身只是一个指向本站的地址,里面不含任何口令或密钥,所以服务端改版你不用重装;改壳的这三项功能才要重装。

  • 提醒

    设置 → 提醒。到点弹系统通知,手机重启后依然生效。提醒只存在这台手机上,不上传服务器。可能晚几分钟到——它不申请精确闹钟权限。

  • 分享进来

    在相册或 PDF 上点「分享」→ 选「AI 助手」,文件直接挂到附件栏,不用先存再传。挂上去只是第一步,读不读得动仍要看当前模型带不带视觉。

  • 桌面组件

    主屏放一个小组件,显示今天的提醒,两个按钮直达拍照提问与新对话（拍照提问同样要模型带视觉才读得出图）。

三步上手

  1. 打开 ai.fenever.xyz/app/（或装上面那个壳,它会自动跳到同一个地址）。
  2. 注册:在登录页切到「注册」,填用户名、密码,再答三条固定的找回问题(忘记密码时用它自己取回)。
  3. 开始聊:换手机、换设备,用同一个用户名再登录一次,记录和记忆都在。

提示「当前没有可用模型,请联系管理员配置模型服务」不是你的问题——那是这台助手的主人还没接上模型,找他。

界面长这样

四张都是线上实拍,不是设计稿。

当前未开启

与其让你现场发现,不如先说清:

  • 联网搜索:代码里有,但这台服务器够不着搜索源,所以它现在给不出实时信息。
  • 代码执行（沙箱）:代码里有,但需要宿主机上的 Docker,当前没开。
  • 扫描版 PDF:图片式的 PDF 要先经过 OCR,今天还不行。有文字层的 PDF 可以直接读,整页贴图的 Word 也一样读不出。
  • 离线使用:没有。界面和数据都在线上,断网就只能等着。

常见问题

要自己配 API 密钥吗?

不用。模型由这台助手的管理员配。普通人在这里什么都不用填。

换手机 / 重装 App,记录会丢吗?

不会丢:聊天记录、附件、长期记忆都在服务器上你这个账号里,用同一个用户名再登录一次就回来。提醒存在旧手机本机,不跟着账号走。

谁能看到我的数据?

只有你。会话、附件、记忆都按账号隔离,别人（包括另一个注册用户）看不到你的。

怎么删干净?

设置里删会话与记忆条目;要注销整个账号,联系这台助手的管理员做删除。删除动作不会把记忆库里的历史一并抹平的那部分,请当面问清再做。

有 iOS 吗?

没有壳,但 Safari 打开 ai.fenever.xyz/app/ 一样能用,加到主屏幕后接近全屏体验;只是没有提醒、分享入口和桌面组件。

打不开怎么办?

这台助手跑在一台个人电脑上,机器关机、断网或重启后没人登录,它就会暂时够不着——那不是你的账号出了问题,等一会儿再试。
