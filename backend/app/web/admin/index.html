token 数一律取上游回传的 usage，服务端不估算：各家分词器不同，本地算出来的数拿去对账是错的。上游没回数字的那几次各项记 0，并在「账全不全」里点出来——那种行的 token 是个下限，不是准确数。日期只认 YYYY-MM-DD，接口也只认 day 这一个参数，所以按人细看就是读完上面这张表，它本来就一人一行。

记忆

这个页面只读条数：长期记忆正文按人隔离，管理员的身份也只是“另一个用户”，跨人去读别人的记忆内容在这套系统里没有接口，也不该有。 /v1/memory/stats 给的是全库合计，不按人拆分，所以上面那张表的「记忆」栏只能是不支持。
