## 🔧 如何将Markdown转换为Word文档

### 方法1：使用Pandoc（推荐，最快）

1. **安装Pandoc**
   - 下载：https://pandoc.org/installing.html
   - Windows安装包：选择MSI installer

2. **转换命令**
   ```bash
   # 进入项目目录
   cd c:\Users\34426\ai-assistant
   
   # 转换测试报告
   pandoc "11-AI智能助手-项目测试报告.md" -o "11-AI智能助手-项目测试报告.docx"
   
   # 转换产品说明书
   pandoc "产品说明书.md" -o "产品说明书.docx"
   
   # 转换安装部署说明
   pandoc "安装部署说明.md" -o "安装部署说明.docx"
   
   # 转换个人总结
   pandoc "费丙乾-项目总结.md" -o "费丙乾-项目总结.docx"
   ```

3. **完成！** 现在可以用Word打开这些.docx文件了

---

### 方法2：手动复制粘贴（无需安装软件）

1. **用记事本或VS Code打开.md文件**

2. **全选内容并复制**（Ctrl+A, Ctrl+C）

3. **打开Microsoft Word**

4. **粘贴内容**（Ctrl+V）

5. **调整格式**：
   - 选中标题 → 设置为"标题1"、"标题2"等样式
   - 选中表格 → Word会自动识别为表格
   - 选中列表 → Word会自动识别为项目符号

6. **另存为.docx格式**

---

### 方法3：使用在线转换工具

1. 访问：https://word.office.com/ 或 https://www.zamzar.com/convert/md-to-docx/

2. 上传.md文件

3. 下载转换后的.docx文件

## ❓ 常见问题

**Q: 为什么不能直接用Write工具生成.docx文件？**
A: .docx是一种特殊的压缩格式（基于Office Open XML），不是纯文本格式。Write工具只能创建纯文本文件，无法直接生成真正的Word文档。

**Q: Pandoc是什么？安全吗？**
A: Pandoc是一个开源的文档转换工具，非常安全可靠，被广泛用于学术和出版领域。

**Q: 如果不想安装任何软件怎么办？**
A: 使用方法2（手动复制粘贴）或方法3（在线转换工具），都不需要安装额外软件。

**Q: 表格格式乱了怎么办？**
A: 在Word中重新插入表格，或者使用Pandoc转换时添加`--reference-doc`参数指定参考模板。
